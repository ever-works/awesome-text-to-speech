## Open-Source TTS Models

- [Bark](https://github.com/suno-ai/bark) - Open-source transformer-based text-to-audio model by Suno that generates speech, music, and sound effects from text prompts. MIT license. ([Read more](/details/bark.md)) `Open Source` `Self-Hosted` `AI-Powered` `Multimodal` `MIT`
- [F5-TTS](https://github.com/SWivid/F5-TTS) - Open-source flow-based text-to-speech model supporting zero-shot voice cloning and multilingual synthesis. Available on GitHub under MIT license. ([Read more](/details/f5-tts.md)) `Open Source` `Self-Hosted` `AI-Powered` `Voice Cloning` `MIT`
- [Kokoro](https://github.com/hexgrad/kokoro) - Open-weight open-source text-to-speech model with 82 million parameters, designed for efficient inference and community fine-tuning. Apache 2.0 license. ([Read more](/details/kokoro.md)) `Open Source` `Self-Hosted` `AI-Powered` `Model Weights`
- [MeloTTS](https://github.com/MyShell-AI/MeloTTS) - Open-source multilingual text-to-speech library developed by MyShell, supporting high-quality inference in multiple languages with CPU and GPU options. MIT license. ([Read more](/details/melotts.md)) `Open Source` `Self-Hosted` `AI-Powered` `Multilingual` `MIT`
- [Piper](https://github.com/rhasspy/piper) - Fast, locally installed open-source text-to-speech system optimized for low-resource devices and offline use, part of the Rhasspy voice assistant ecosystem. MIT license. ([Read more](/details/piper.md)) `Open Source` `Self-Hosted` `Free Plan` `Local` `Offline`
- [Tortoise-TTS](https://github.com/neonbjb/tortoise-tts) - Open-source text-to-speech model focused on highly realistic voice synthesis with multi-voice capabilities and deep diffusion-based architecture. MIT license. ([Read more](/details/tortoise-tts.md)) `Open Source` `Self-Hosted` `AI-Powered` `Voice Cloning`
